How to use Lemma

From install to a fully explained solution in a couple of minutes.

1

Install & sign in

Download the APK and install it. Create an account (or try guest mode) — signing in unlocks cloud sync across your devices.

2

Enter the problem your way

Type it, tap the 🎤 mic to speak it, attach a photo of the figure, or scan a textbook page with the 📸 camera. Add extra instructions if you like.

3

Read the guided solution

Lemma returns numbered step cards with clear notation and a highlighted final answer, and draws the figure on the 3D canvas above.

4

Copy or download

Copy a single step or the whole solution, save the drawing as an image, or export a PDF (figure + selectable solution text).

5

Sketch it yourself

Open the Drawing tool and use Line, Rectangle, and Circle with Smart Dimension to set exact lengths and angles — the parametric engine keeps everything connected.

6

Make it yours

In Settings, switch language (EN / RU / HY), choose Light / Dark / System theme, and add your own Gemini API keys (with automatic fallback).

7

Find it later

Everything lands in History and mirrors to the cloud. Swipe to delete (with undo), rename, or re-download on any device.

8

Learn the theory

Browse the built-in Theorems & Formulas library by grade, with proofs, worked examples, and quick knowledge-check quizzes.

Frequently asked questions

Is Lemma usable offline?

Yes. You can sketch, dimension, edit, and review your saved history entirely offline. When you reconnect on a signed-in device, the Cloud Sync Manager pushes your offline work to the database automatically.

What is a parametric sketcher?

Unlike a paint app, Lemma stores lines as mathematical relations. Select a line and change its length (say 50 → 100) and the connected edges stretch and follow it, preserving your geometry.

How do I run the AI for free?

Open Settings → Set Personal API Key and add one or more Gemini API keys. You can switch each key on or off, and Lemma automatically falls back to the next one if a key runs out of quota. You can also unlock Lemma Pro.

Which languages are supported?

The interface and the AI's step-by-step explanations are available in English, Russian, and Armenian. You can switch instantly from Settings or the language chip on the welcome screen.

Can I export my solutions?

Yes — copy any step or the whole solution to your clipboard, save the figure as an image to your gallery, or export a PDF that contains the figure plus the solution as real, selectable text.

Where are my API keys stored?

Keys are kept on your device and mirrored to your own account so they follow you across devices. For a hardened production setup, route requests through a server proxy rather than embedding keys on the client.
